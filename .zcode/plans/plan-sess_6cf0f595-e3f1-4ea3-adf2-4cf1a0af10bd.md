# 以 SpeakUp 原型为功能基准：全面对齐补齐

原则：原型页面集 = 功能规格；我们已超出原型的部分保留（课堂指派/关卡地图/AI 出题/词汇 CEFR/模拟分/真实引擎/40 人并发）。演示专用功能不搬：模拟录音模式、身份切换器、原型免责文案、教师"教学资源"页（admin 已覆盖）。

## P1 学生端核心补齐
- **结果页每题回看弹窗**：每题行加 ▶ 按钮 → Dialog 显示题干/转写/分数 + `<audio>` 回放自己的录音（`/attempts/{id}/audio`，教师面板已有同款可照抄；PlanAttempt.attempt_id 数据已齐）
- **帮助与设备页 `/help/:code`**：设备检查清单（耳机/麦克风授权/音量）、扬声器测试（speechSynthesis 播测试句）、麦克风测试（getUserMedia 试授权即时反馈）、FAQ（可再录/非官方成绩说明/数据保存说明）；StudentShell 加「帮助」入口
- **录音中离开确认**：录音时路由拦截弹「先把这次开口留住？」（TanStack useBlocker + beforeunload 兜底刷新场景）
- **我的课堂页 `/classroom/:code`**：课堂码大卡+复制、课堂信息、**换名字/退出课堂**（清本地身份回加入页——目前学生无法换名，这是缺失入口）、放心开口约定文案

## P2 成长与激励补齐（轻后端）
- 后端 trail 聚合扩展：`TrailData.total_minutes`（Σ作答时长）+ `vocab_counts {A2,B1,B2}`（累计命中词次数）
- **成长页统计卡 4 格**：累计开口分钟 / 完成练习次数 / 当前档位 / 坚持天数 + **词汇生长条形图**（A2/B1/B2 三条）
- **周目标设置**：目标环点击弹 3/5/7 天选择（localStorage，常量提取到 lib 供首页/成长页共用）
- **消息通知中心**：StudentShell 铃铛下拉——本地派生内容（今日任务进度、连胜鼓励、最近新徽章），不做后端通知系统

## P3 教师端补齐（纯前端，数据已齐）
- **统计卡 4 格化**：班级学生 / 今日完成 n/班额 / 班级均分（前端算）/ 值得关注（7 日未练数）
- **名单筛选 + 搜索**：状态下拉（全部/已完成/练习中/7天未练，用 has_pending/done_count/inactive_days7 前端过滤）+ 姓名搜索框
- **导出 CSV**：当前名单（姓名/档位/完成/均分/状态）前端生成下载（复用原型 CSV 序列化逻辑，含 BOM 防中文乱码）
- **教学建议卡**：静态轮换文案（原型搬）+ **课堂入口分享**按钮（复制 /j/{code} 链接）

## P4 探索、管理与内容补齐
- **探索页**：完成状态筛选（未开始/进行中/已完成，用 rounds_done）+ 标题/主题搜索；预览弹窗加「整篇跟读」入口 → `/practice`（公开整篇页，不计分）
- **词表导入预览**：前端 CSV 解析校验（搬原型 parseCSV：表头/档位合法/重复检测）→ 预览统计+样例词条 → 确认后才上传；加「下载模板」按钮
- **每题中文翻译（可选字段）**：RepeatSentence/ScenarioQuestion/Passage 加 `translation` 可空列（迁移）+ admin 录入表单 + 学生端题干下方显示（未填则显示题型固定提示，兼容现有内容）

## P5 收尾
每阶段：实现 → lint/tsc/build → 浏览器实测；最后全量后端测试 + CLAUDE.md 差距清单勾销 + 提交推送。

## 后端改动汇总（很小）
trail 聚合两个字段、translation 三列迁移、admin 请求模型透传——其余全部纯前端。无新表、无新服务。
