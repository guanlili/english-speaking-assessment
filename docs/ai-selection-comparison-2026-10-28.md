## 四、价格之外的四个决定性因素

**1. 数据合规(刚性约束)**:学生作答语音属于未成年人个人信息。按《个人信息保护法》与《生成式人工智能服务管理暂行办法》,使用境外模型 API 意味着数据出境,须通过数据出境安全评估——对校级场景实际不可行。**因此国外模型在本场景不是「贵不贵」的问题,而是「不可选」**。国内厂商(火山/阿里/腾讯/讯飞)均满足数据不出境要求。

**2. 延迟与并发(课堂体验)**:40 人整班齐交时,平台 8 通道并发评分、2 分钟内全班出分。国内厂商国内节点单次往返延迟数十毫秒级;海外 API 普遍数百毫秒起且有不可控波动,课堂高峰体验无法保证。

**3. 英语口语识别质量**:豆包 ASR 对中国学生英语口音的识别质量经本平台全量生产验证(3,063 次作答,0 重试浪费、全部成功出分),这是选型的实证依据,不是纸面参数。

**4. 一站式管理**:LLM + ASR + TTS 同厂商(火山引擎),密钥、账单、配额、告警统一管理,运维与对账成本低;多厂商拼装会带来多套密钥/多张账单/多次排障的隐性成本。

## 五、对学校的三个要点

1. **当前选型 = 合规前提下的价格洼地**:三大 AI 能力全部国内、全部按量付费、无任何预付/授权费;按目录价口径,当前用量下 AI 费用每月百元以内(主报告 §2:¥95–125/月),还预留经济档开关可再降。
2. **成本有硬护栏**:单次评分输出上限(2,048 token)、调用限流、内容寻址缓存三层护栏,即便模型单价波动或用量激增,费用上限清晰可算(主报告 §2.2)。
3. **不与任何厂商绑定**:平台评分引擎从架构上就是**可替换接口设计**(评分/识别/合成三个引擎均可独立替换),未来出现更优或更廉价的国产模型,可配置级切换、零代码改动、历史数据不受影响。
