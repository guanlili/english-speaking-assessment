## 1. 产品概览

### 1.1 定位

面向学校英语口语课堂的一体化平台：教师用现成题库组课，课上发布、全班同时开口；每次作答留下原始录音、转写、参考分与教师点评；课后可按班级、学生、题目回看，并导出学情报告。平台按学校（租户）独立运营，校与校之间数据强隔离。

### 1.2 一条完整教学链路

**备课**（题目库）→ **建班**（课堂码 + 导入学生）→ **发布**（课堂练习 / 课后作业 / 模考 / 补练）→ **作答**（设备检查、录音、评分）→ **反馈**（转写、参考分、AI 建议、教师点评）→ **跟进**（补练、讲评、课堂消息）→ **复盘**（课堂面板、学情报告、导出）。

### 1.3 核心能力

- **四类口语题型**：文章朗读、听句复述、情景问答、题目说明，可混合组卷。
- **分级考试题型**：托福听后复述、雅思 Part 1/2/3、面试问答，与五级词库共用难度分级。
- **课堂闭环**：实时状态、课堂诊断、逐题点评、指定补练、补练效果对比、课堂讲评、求助与提醒。
- **词汇学习**：五级词库、公共/本班词书、任务发布、看义/听音拼词、限时测验、错词本、AI 学情。
- **模考与自动考试**：整场限时、逐题计时、防切屏；题干音频与等待/准备/缓冲阶段自动推进，断点可续考。
- **数据与导出**：课堂面板、学生成长、口语原音频 ZIP、学生学情 PDF、班级报告 PDF、全平台使用 CSV。
- **平台保障**：多租户行级隔离、中英双语、电脑/平板/手机三端自适应、公开站点与平台更新日志。

### 1.4 四类角色与入口

| 角色 | 如何登录 | 能做什么 |
|---|---|---|
| **平台管理员（运营）** | 平台运营入口或主登录页邮箱账号 | 开校 / 停校、平台账号与权限、五级词库、课堂管理、平台大盘、全量数据导出；**不进入学校教学业务页** |
| **学校管理员** | 学校专属入口或主登录页邮箱账号 | 本校教师账号、单元/句型库/词库、本校全部课堂与学情、班级报告 |
| **教师** | 邮箱账号（学校管理员创建） | 自己负责的课堂：建班、导入学生、出题选题、发布、点评、补练、导出 |
| **学生** | 学号 + 密码，或教师发的课堂链接 | 今日任务、口语作答、词汇学习、我的成长、下载自己的录音与学情报告 |

## 2. 快速上手

### 2.1 平台运营：开通一所学校

1. **开校**：在「学校管理」新建学校，填写学校码（slug）与中英文名称；系统生成学校专属登录链接 `/s/学校码/login`。
2. **建管理员**：为该校创建一个学校管理员账号，把专属登录链接与初始密码安全地交给对方。
3. **交付使用**：学校管理员创建教师账号、导入学生后即可开课；平台侧在大盘查看使用量、稳定性与费用。

停用学校会立即挡住新登录，已登录会话失效；**停用不删除任何数据**，重新启用即可恢复。

### 2.2 学校管理员：把学校架子搭起来

1. 在「教师管理」创建本校教师账号，设置初始密码并转交。
2. 在「题目库」维护主题、单元、篇目、复述句、情景问法与题目说明；需要时批量导入。
3. 在「校内管理」维护单元、句型库、本班/公共词库；五级词库为平台授权数据，学校侧只读。
4. 进入「我的课堂」建班、导入学生，并以本班负责人身份安排练习；需要把课堂交给某位教师时，由平台运营在「课堂管理」中绑定授权教师。

### 2.3 教师：第一堂课

1. **建课堂**：填写课堂名称、年级/班型、班额与教学目标，系统生成课堂码。
2. **导入学生**：粘贴名单批量导入，每行「学号 姓名」；学生默认初始密码统一，可单个或批量重置。
3. **选题**：在「练习安排」勾选题型，从题目库挑选篇目、复述句、情景主题或说明页，调整顺序并可预览学生题单。
4. **发布**：命名为本轮练习，选择「课堂练习」或「课后作业」；需要考试时打开模考开关。
5. **课后**：在「学生结果」看实时状态、逐题作答、听录音、写点评、指定补练；在「发布历史」回看每一版题单与成绩。

### 2.4 学生：进入课堂

1. 打开教师给的课堂链接，或用学号登录后输入课堂码。
2. 首次作答前完成一次**设备检查**：允许声音与麦克风，试录并回放确认。
3. 在「今日任务」按顺序完成练习或考试；每道题的录音、转写与反馈都会保留。
4. 到「词汇学习」做老师发布的词单，或自主挑词练习；到「我的成长」查看参考分、进步轨迹与阶段报告。

## 3. 账号、登录与权限

### 3.1 登录入口

| 入口 | 地址 | 适用人群 |
|---|---|---|
| 主登录页 | `/login` | 教师、学校管理员（邮箱）；学生切换到「学生登录」用学号 |
| 学校专属入口 | `/s/{学校码}/login` | 某所学校的师生，页面显示学校名称 |
| 平台运营入口 | `/platform/login` | 平台管理员，只能进入平台管理台 |
| 学生课堂链接 | `/j/{课堂码}` | 学生打开后登录并直接进入该课堂 |
| 我的班级 | `/join` | 已登录学生查看全部班级、凭课堂码加入新班 |

### 3.2 账号规则

- 学校管理员账号由平台创建；教师账号由学校管理员创建；学生账号由教师或学校管理员批量导入。
- 学生默认初始密码由学校统一约定，**不强制首次改密**；学生可在账户菜单自愿修改。
- 教师/管理员忘记密码可在登录页通过邮箱找回；学生密码由教师或学校管理员重置。
- 学校被停用后，该校所有账号立即无法登录，已登录会话到期失效。
- 一个学生可同时在多个班级：各班任务与成长分别记录，顶部只显示账号合计。

### 3.3 权限矩阵（摘要）

### 3.4 数据边界（六条）

1. **学校之间完全隔离**：师生、课堂、题库、成绩互不可见；跨校访问按「不存在」处理，由数据库层强制。
2. **教师之间互不可见**：教师只能看自己负责的课堂；学校管理员可看本校全部。
3. **学生只看自己**：看不到同学的数据，也进不了任何管理页面。
4. **课堂码只用于入班**：凭课堂码查看不到任何班级数据；跨校课堂码无效。
5. **平台与学校两套身份**：平台凭证碰不到学校业务页，学校凭证碰不到平台管理面。
6. **停用立即生效**：停用不删数据；重新启用后原账号与记录仍在。

## 4. 题目库与内容准备

### 4.1 四类题型

| 题型 | 学生看到什么 | 出题与组织 | 计分口径 |
|---|---|---|---|
| **文章朗读** | 文章或逐句段落，录音提交 | 篇目可整篇出题，也可拆分为逐句；逐句朗读时长可设 1–180 秒，未设置时按句长估算 4–30 秒 | 跟读参考分：对照原文算完整度与流利度 |
| **听句复述** | 听标准音后复述，可设重听次数 | 独立句库，可挂在篇目下；从篇目自动生成时默认取 3 句 | 跟读参考分：完整度与流利度 |
| **情景问答** | 按主题成组出题，一问一答 | 主题下维护多条问法，可设中文提示与建议秒数（普通题 10–60 秒，考试题最长 300 秒） | 问答参考分 + AI 四维模拟分与改进建议 |
| **题目说明** | 纯文字引导页，读完点「继续」 | 独立说明库，可复用；组卷时穿插在题与题之间 | 不录音、不计分、不计入完成分母；模考中按设定秒数计时，可提前继续 |

各题型互相独立：组卷时可以只选一种，也可以混合；学生题单按教师排定的顺序出现。

### 4.2 题库结构

- **主题 · 单元**：单元用于组织教学顺序（学习路径默认按单元顺序解锁，平台运营可在「课堂管理」切换为一键全开）；主题用于组织情景问答。
- **篇目 → 句子**：篇目是朗读与复述的内容源；拆分后的文章在发布时按句展开，学生逐句朗读。
- **问法 → 主题**：一个情景主题下可有多条问法，发布时按主题整组抽取或指定题目。
- **说明页**：独立文字页，常用于考试开场说明或题型引导。

### 4.3 分级考试题型

| 题型 | 适用 | 关键设置 |
|---|---|---|
| 托福听后复述 | TOEFL Listen and Repeat | 播放音频后复述；按级别标注 |
| 雅思 Part 1 / 2 / 3 | IELTS Speaking | Part 2 支持话题卡要点与 10–180 秒准备时间，作答最长 300 秒 |
| 面试问答 | Take an Interview | 按考试问法组织，可长回答 |
| KET / PET 课堂版 | 日常课堂 | 不单设题型，通过更短文本、更短秒数与内容难度体现 |

考试题型与五级词库共用级别口径；未标注考试字段的旧题，含义与流程完全不变。

### 4.4 内容管理操作

- **新建 / 编辑 / 删除**：篇目、单元、复述句、情景主题与问法、说明页均可在题目库维护。
- **复制**：篇目（连同子篇与配套复述句）、情景主题（连同全部问法）、单句、单题、说明页均可复制；复制后直接进入副本编辑，不改原题与历史成绩。
- **批量导入 / 导出**：下载 Excel 模板，填写后先预览（查重、缺字段、格式错误提示），确认后入库；失败行可下载错误文件；支持整库导出备份。
- **查重**：导入与新建时按标题/正文/题目文本归一化比对，重复内容会提示。
- **AI 起草**：情景问答题可按主题生成草稿，教师逐条审改后采纳；AI 只起草，不直接入库。
- **自动拆句**：长文章可一键拆分为逐句朗读，拆句结果可再编辑；正文变化会清空原逐句时长配置，避免错句。
- **标准音与考试音频**：可为题目生成或上传标准音；自动考试要求说明、复述、问答题配齐音频，可在题目设置里生成或沿用既有标准音。

### 4.5 发布快照：历史不漂移

教师每次发布都会生成一份**不可变题单快照**：题目内容、顺序、时长、考试设置全部冻结。学生作答与教师回看始终按发布当时的快照解释；之后修改题库只影响下一次发布，不影响已发布练习与历史成绩。

## 5. 课堂与教学组织

### 5.1 建班与学生

- 新建课堂时填写名称、年级/班型、班额上限（1–100，教师建班默认 60；运营生成课堂码时默认 40）与教学目标；系统生成课堂码。
- 学生用学号登录后凭课堂码加入；也可由教师在名单中粘贴「学号 姓名」批量导入账号。
- 教师可查看名单、重置单个或批量密码、移出名单；移出只解除账号绑定，历史仍归本课堂。
- 平台管理员可在「课堂管理」生成课堂码、绑定/解绑授权教师、切换顺序解锁或一键全开、启停课堂、开关学情报告中的班级位置。

### 5.2 发布练习

在课堂面板「练习安排」中：

1. 勾选题型（朗读 / 复述 / 问答 / 说明）。
2. 从对应题库挑选内容，可搜索、跨页选择、调整顺序。
3. 设置练习名称，必要时插入说明页。
4. 预览学生题单，确认后发布。

发布位置有两种：

- **课堂练习**：替换当前课堂的统一练习，全班即刻看到。
- **课后作业**：独立于课上练习，学生课后完成；可撤回，撤回不影响课上练习。

教师也可以「恢复自主练习」，撤掉统一指派，让学生按各自学习路径练习；已提交记录保留。

### 5.3 模考

| 规则 | 说明 |
|---|---|
| 发布位置 | 仅课堂练习；课后作业不能设为模考 |
| 限时 | 5–240 分钟，以服务器时间为准 |
| 开始 | 学生在确认页点「开始考试」才落计时；到时自动交卷 |
| 逐题计时 | 题目出现即开始计时；雅思 Part 2 先计准备时间；到时未答自动跳过 |
| 作答次数 | 每题只能作答一次（断网重传不受影响） |
| 防切屏 | 记录切屏次数与离屏时长，教师面板可见；不自动判定作弊 |
| 过程反馈 | 考试中不显示逐题分数与建议，结果页统一查看 |
| 结果页 | 保留录音回放；不提供重练、换题、重答入口 |

### 5.4 自动考试流程

新发布的模考默认使用自动考试：题干音频、等待、准备、录音前缓冲按题目设置自动推进。

- 说明页：等待后播放音频，播完点「下一题」。
- 复述题：播放题干音频，缓冲后开始录音。
- 问答题：播放题目后给准备时间，再缓冲、录音。
- 首次开始或返回时做一次设备检查；之后题目自动推进，不需要反复授权。
- 退出或刷新不暂停整场计时；返回时按服务器时间恢复当前阶段，音频阶段会重播当前题干。
- 录音过程中断网会保留本地草稿与原幂等键，恢复网络后可重传；已上传的题不会因刷新丢失。
- 整场到时拒绝新提交；历史作答只读。

### 5.5 课堂面板

课堂面板分三个页签：

- **练习安排**：选题、排序、预览、发布；草稿自动保存（仅自己可见，发布后学生才收到）；可从历史发布复制题单再改。
- **学生结果**：实时状态（未提交 / 评分中 / 已提交，练习轮另标已读 / 未读与「7 日未练」）、课堂诊断、待办事项、逐题作答与录音回放、学生历史轮次与进步轨迹、点评与补练入口。
- **发布历史**：每一版发布的题单、完成情况、成绩单导出、讲评入口。

面板还会显示班级趋势、得分薄弱题、设备/音频/上传异常，帮助教师课上快速处理。

### 5.6 点评、标重点与补练

- **教师点评**：对单题写评语、标重点、加复核标签；点评不改 AI 分数，按版本保存，多人同时修改会提示冲突。
- **指定补练**：选择学生与题目，从原发布快照出题；补练不替换当前课堂练习，学生按本人任务完成。
- **补练效果**：对比原作答与补练后的最新作答，同评分引擎下给出参考分变化与证据；考试未结束或反馈锁定时不展示。
- **撤销补练**：教师可撤销未完成的补练；已上传的录音按规则清理。

### 5.7 讲评与课堂小结

- 教师可针对一次发布写**私有讲评笔记**与小结草稿，反复修改，不影响学生。
- 确认后**发布课堂小结**，学生在首页与学习消息中可见；教师可撤回。
- 考试进行中，不能讲评该学生尚未交卷的作答。

### 5.8 课堂消息

- **学生求助**：学生可选择类型、填写说明提交；教师端集中显示待处理求助。
- **教师答复**：带版本保存，学生看到最新答复；教师可继续补充。
- **教师提醒**：可设截止时间；支持「再次提醒」，同一提醒链 60 秒冷却，避免刷屏。
- **已读确认**：学生确认已读；教师端区分未读/已读/已处理。
- 学生首页与「学习消息」入口可直接查看当前求助、答复、提醒和公开小结。

### 5.9 班级报告 PDF

教师可导出本班分析报告，走「录音导出 / 下载中心」：

- 章节：班级概览（活跃人数、作答量、问答均分、跟读完整度）、分数分布、进步趋势、题项对比（得分最低的前 20 个题位）。
- 范围默认最近 90 天；仅本班负责教师或学校管理员可导出，学生不可代导。
- 未结束的考试不计入；正文不含作答 ID 与外链。
- 生成后保留 7 天，可重复下载。

### 5.10 课堂删除

教师或学校管理员删除课堂时，可选择同时清理该课堂的成员绑定、口语/词汇会话与发布历史；学生账号与其他课堂不受影响。仍有评分中作答时暂不允许删除。

## 6. 词汇学习

### 6.1 五级词库

平台内置一套分级词库，顺序固定：

**KET → PET → 学术词汇 → 四级词汇 → 雅思 & 托福词汇**

- 同一个词出现在多个级别时，按**最早（最易）一级**计入。
- 词组单独标记，口语用词统计暂不计入；待核对的词条在核对前不参与统计。
- 五级词库只由平台管理员导入维护；学校管理员与教师按级别选词教学，只读。
- 口语问答的用词统计与背单词模块共用这套分级数据；历史作答不回填、不重算。

### 6.2 词书

| 类型 | 谁维护 | 用途 |
|---|---|---|
| 公共词书 | 学校管理员 | 本校范围内可选的公共词单 |
| 本班词书 | 本班教师（学校管理员亦可） | 按班级进度自建词单，仅本班可见 |

- 支持 CSV 导入：先预览（拼写、释义、词性、重复项校验），确认后入库。
- 教师可用 AI 起草词条：按主题、级别、数量生成草稿，逐条编辑后加入本班词库；AI 只起草，不直接发布任务。
- 词条包含拼写、词性、中英释义、可接受拼写变体与标准音。

### 6.3 发布词汇任务

- 选择词书与词条（可按五级 level 过滤），设置截止时间与是否「纯听音」。
- 发布时生成**词单快照**与**固定名单**：之后新增或转班学生不改变本次完成率分母。
- 新发布不会再自动结束旧任务；旧任务可保留、结束或归档。
- 纯听音任务要求全部词条有标准音；缺标准音时，未作答的词在学生端自动回落为看义拼词。
- 截止时间以服务器时间为准；过期不能开新轮，也不能继续作答。

### 6.4 学生练习

- **任务卡**：显示未开始 / 进行中 / 已完成、截止时间、首答正确率、最好成绩。
- **练习轮**：看中文释义拼英文，或听标准音拼写；提交后即时反馈，可「再练一轮」。
- **限时测验**：先看规则，点「开始测验」才计时；服务器计时，每题只能提交一次；提交后不提前显示对错，等教师公布成绩与答案。
- **错词本**：第一次没拼对的词自动收录，答对也不会移除；可一键复习错词。
- **自主练习**：从公共词书或本班词书挑词自练，与老师任务分开记录，不影响任务成绩。
- **AI 学情**：单词讲解、本轮建议与整体学习建议，按需生成。

### 6.5 判分口径

- 统一规范化拼写（全半角、首尾空白、大小写）；只认快照拼写与显式登记的英美拼写变体，**不收同义词**，不自动放宽复数或连字符。
- 统计与错词本一律看**首答**；重试轮不改变任务首答正确率。
- 测验中未作答的题，不向学生端泄露拼写。

### 6.6 教师查看与导出

- 「完成情况」显示任务进度、首答正确率、轮次与成绩；课堂面板可在「口语练习 / 词汇」之间切换。
- 可分别公布**成绩**与**答案**；公布答案后学生错词本开始收录本次错词。
- 支持导出任务成绩 CSV（文件名带日期）与测验成绩 CSV（文件名带发布版本号）。

## 7. 学生端

### 7.1 今日任务

一张卡片集中展示当前练习或考试：题量、已完成数、模考限时、开始 / 继续入口。课后作业、指定补练、求助与提醒、公开课堂小结在同一页可直接使用。没有统一指派时，显示自主练习入口。

### 7.2 作答流程

1. 进入练习先做设备检查（允许声音与麦克风、试录、回放确认）。
2. 按题序作答：朗读看文本录音，复述听标准音后录音，问答看题准备后录音，说明页读完继续。
3. 录音上传成功即推进下一题，不等待评分。
4. 普通练习每题可重录、重练；模考按第 5.3 节规则执行。

### 7.3 反馈与分数口径

| 分数 | 含义 |
|---|---|
| **参考分（百分制）** | 衡量开口的量与节奏：问答按词量（约 25 词达到内容分上限）与语速稳定度；跟读按对照原文的完整度与流利度。不判断用词、语法或是否切题 |
| **模拟分（0–9）** | AI 按流利度、词汇、语法、任务完成四维打分后映射；仅在启用模型评分时出现，模型失败时显示「建议暂缺」，不出假分 |
| **词汇级别统计** | 用词来源属于五级词库的哪一级，只描述用词来源，不代表能力等级 |

所有分数都标注为**练习参考分**，不是官方考试成绩；课堂练习与模考均不用于成绩单或对外证明。

### 7.4 我的成长

- 累计开口时长、完成练习轮数、坚持天数。
- 参考分与进步轨迹：按日汇总情景问答参考分与复述完整度。
- 五级词库用词统计、表达收藏、句型收藏（跨设备同步）。
- 历史练习：最近 100 轮，可逐轮回看每题转写、参考分与建议。
- 阶段报告：可提交生成个人学情 PDF（见 8.1）。

### 7.5 主题探索与自主练习

按单元浏览题库内容，可自主练习未被统一指派的篇目、复述句与情景问答。课堂设置为「顺序解锁」时按单元逐个推进；平台运营开启「一键全开」后全部单元可练。

### 7.6 我的班级

多班学生登录后先进入「我的班级」，选择要进的班；顶部显示账号合计 XP 与最长连胜，各班成长分开记录。也可输入课堂码加入新班。

### 7.7 学习消息

首页铃铛与「学习消息」中查看：今天的练习进度、教师提醒、求助答复、公开课堂小结、新徽章。提醒可确认已读；求助可撤回本人提交。

### 7.8 下载中心

学生可导出：

- **我的口语录音 ZIP**：只含自己的原始录音；默认最近 90 天，最长 90 天；没有录音时不生成空包。
- **我的学情报告 PDF**：中文报告，含概览、趋势、弱项、作答证据与教师建议；没有已出分作答时生成一份说明性的空报告。

文件保留 7 天，过期自动清理；可重新生成。

### 7.9 设备与帮助

- 支持电脑、iPad、手机；iPad 建议使用较新版本 Safari 或 Chrome，戴耳机可减少回声。
- 只在作答时申请麦克风，不申请摄像头；拒绝授权不影响账号，但无法完成录音题。
- 「帮助与设备」页含登录方式、进班三步、设备检查与常见问题。

未登录访客可访问四个公开页：落地页 `/`、关于 `/about`、帮助 `/help`、隐私 `/privacy`。已登录用户打开 `/` 会自动分流到平台大盘、我的班级或我的课堂。公开页配置了标题、描述、分享卡片、`robots.txt` 与 `sitemap.xml`；带账号或课堂码的路径不进入搜索引擎索引。

## 9. 平台特性与安全

### 9.1 多租户隔离

- 每所学校是独立租户；业务表带租户列，数据库启用**行级安全（RLS）**，并在应用层做第二道校验。
- 跨校读取、编辑、删除、复制一律拒绝；列表接口只返回本校数据。
- 学校停用后新登录被挡，已登录会话失效；数据保留，可恢复。
- 平台管理员与学校账号是两套独立身份，互不进对方界面。
- 教师只能看自己负责的课堂；学校管理员看本校；学生只看自己。

### 9.2 双语与三端

- 所有用户可见界面支持中文 / English 切换，语言偏好按浏览器记忆。
- 电脑、iPad、手机三端自适应：手机底部导航（今日任务 / 词汇 / 成长），桌面侧栏；表格可横向滑动。
- 表单控件字号不小于 16px（避免 iOS 聚焦放大），高频触控目标不小于 44px。

### 9.3 隐私与数据

- **保存内容**：账号信息（密码只存哈希）、作答录音与转写、评分与学习记录、词汇进度与错词、教师点评与补练安排、用户主动生成的导出文件。
- **谁能看到**：学生本人；本班教师与学校管理员（本校范围）；平台运营方仅用于开通、运维与故障处理；其他学校一律拒绝。
- **麦克风**：只在作答时申请，不申请摄像头；录音地址使用随机标识，不能靠猜测访问。
- **浏览器本地**：登录凭证与角色标记、语言与主题偏好、本机班级身份；清除浏览器数据会清掉这些内容，但不影响服务端已保存的作答与成绩。
- **删除**：账号或作答数据归属学校，需通过学校管理员发起，由学校与平台运营方确认范围后执行。

### 9.4 运行与可靠性

- 评分异步执行：录音上传成功即可进入下一题，评分结果稍后回填；断网重传使用幂等键，不会重复计分。
- 课堂面板在有人评分中时自动轮询，最后一人提交后通常 2 分钟内一致。
- 平台每日自动备份数据库与音频存储，支持按备份恢复；恢复流程与保留周期由运维约定执行。
- 生产全程 HTTPS；密码哈希存储；运维巡检只检查服务可用性与磁盘占用，不采集学生作答内容。

## 10. 常见问题

**Q1：忘记密码怎么办？**
教师在登录页点「找回密码」，按邮箱收信重置；学生由教师或学校管理员在成员管理里重置。

**Q2：学生第一次登录用什么密码？**
使用学校统一约定的初始密码；不强制改密，学生可在账户菜单自行修改。

**Q3：课堂链接打不开，提示页面不存在？**
课堂可能已被删除或重建，旧链接随之失效。向老师要新的课堂码或链接，不要在旧链接上反复尝试。

**Q4：点了麦克风没反应，或一直录不上？**
先完成设备检查并允许声音与麦克风；浏览器里拒绝过一次后要在站点设置里手动恢复。iPad 建议用较新版本 Safari/Chrome，戴耳机可减少回声。

**Q5：分数为什么是这个数？算不算成绩？**
界面上的分数都是练习参考：跟读看完整度与流利度，问答看开口量与节奏，另有 AI 四维模拟分。它不是官方考试成绩，不能用于成绩单或对外证明。

**Q6：老师后来改了题库，之前发布的练习会变吗？**
不会。已发布练习按发布当时的题单快照解释；题库编辑只影响下一次发布，历史作答与结果保持原样。

**Q7：换设备或换浏览器，进度会丢吗？**
用同一学号登录，练习与成绩跟着账号走；设备上缓存的班级身份只在本机有效，换设备后重新进一次班即可。

**Q8：一个学生同时在几个班，记录会混在一起吗？**
不会。进入「我的班级」选班，各班任务与成长分别记录，顶部只给账号合计。

**Q9：学校被停用后会怎样？**
该校所有账号（包括已登录会话）立即失效；联系学校管理员与平台运营方恢复，数据不会删除。

**Q10：录音和报告能保存多久？**
作答录音随学习记录保留，具体期限由学校与平台运营方约定；用户主动导出的 ZIP/PDF 在下载中心保留 7 天，过期自动清理，可重新生成。

**Q11：外教可以把界面切成英文吗？**
可以。侧栏/页头有中英切换，选择按浏览器记忆；公开页与登录页同样支持。

**Q12：能在手机或 iPad 上完整使用吗？**
可以。学生端、教师端与管理端均适配三端；iPad 是课堂主力设备，建议使用较新系统浏览器。

## 附录 B · 关键术语

| 术语 | 含义 |
|---|---|
| 参考分 | 百分制练习参考分，衡量开口量与节奏、跟读完整度与流利度，不代表官方成绩 |
| 模拟分 | AI 四维评分映射出的 0–9 分，仅作改进参考 |
| 发布快照 | 每次发布冻结的题单与设置，保证历史作答不因题库修改而变 |
| 课堂练习 / 课后作业 | 两种发布位置：前者替换课上统一练习，后者独立布置、可撤回 |
| 补练 | 针对个别学生与指定题目，从原发布快照重新出题 |
| 讲评 / 课堂小结 | 教师私有笔记与可发布给学生的公开小结 |
| 五级词库 | KET、PET、学术词汇、四级词汇、雅思&托福词汇五级分级数据源 |
| 错词本 | 首次拼错的词自动收录，答对不移除，可反复复习 |
| 自动考试 | 题干音频与等待/准备/缓冲阶段自动推进的模考流程 |
| 行级安全（RLS） | 数据库层强制按学校隔离数据的安全机制 |
