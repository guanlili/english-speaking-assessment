## 数据与安全口径

- **无真实学生信息**：测试校为 `seedpilot-*` / `bug-verify-*` 等本地合成租户，学生为 `学生1-1`、`s20001` 等代号；导出样例不含真实姓名、手机号、邮箱。
- **已脱敏**：报告中的本地测试口令、合成邮箱、完整 UUID、本机绝对路径、`127.0.0.1`/`localhost` 地址均已替换为占位描述；截图中的侧栏账号/邮箱块已由原始取证脚本隐藏。
- **未入库**：`scratch/`（含浏览器 storage state/token）、原始 HTTP 响应 JSON、测试日志、`htmlcov` 等临时产物全部排除；报告正文中提及的 `scratch/...` 是取证时的本地临时文件，不在本仓库。
- 仍保留的课堂码、合成学生代号仅用于复现本地场景，不对应真实学校。
