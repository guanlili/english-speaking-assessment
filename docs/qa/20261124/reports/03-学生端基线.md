## 4. 缺陷清单

### D-S1 · P2 · PK 大厅加入/离开后前端状态不即时刷新

- **级别**：P2（体验/状态反馈缺陷；服务端状态正确，刷新或后台重拉后恢复）。
- **现象**：浏览器点击「加入 PK」后，界面仍显示「加入 PK / 排队 0 人」；点击「离开排队」后仍显示「已排队，等待对手配对…」。重载页面后排队人数与按钮状态才与服务端一致。
- **复现步骤**：
  1. 教师 API 开厅后，学生进入 `/vocab/SD100X/pk`；
  2. 点击「加入 PK」，观察大厅卡片文案与排队数；
  3. 再点击「离开排队」，观察文案；
  4. 重载页面对比。
- **证据**：`pk-lobby-final.json`（服务端 `queue_count=1 / my_status=waiting`，后 `left`）；代码 `frontend/src/components/Vocabulary/Pk/PkArena.tsx`：大厅查询 key 为 `["vocab", code, "pk-lobby"]`（L43），而 join/leave mutation 的 `onSuccess` 失效查询 key 为 `["vocab", code, "pk"]`（L144、L158），第三段 key 不匹配，`invalidateQueries` 前缀无法命中大厅缓存。
- **影响面**：学生在 PK 大厅误以为加入/退出未生效，可能重复点击；不影响服务端排队与配对正确性。
- **建议**：将 join/leave/answer mutation 的失效 key 对齐为 `["vocab", code, "pk-lobby"]`（或按 `pk` 前缀统一收敛），加入/离开后即时重拉大厅快照。

### D-S2 · P2（待产品确认口径）· PK 对局在双方仅答 2/5 题时提前结算

- **级别**：P2（口径待产品确认；若「超时跳过即视为已处理」为设计意图，则仅需核对计数与结算阈值实现）。
- **现象**：对局 `5f2482ca-…` 双方各仅 2 条作答行，`answered_count` 即被抬到 5，对局以 `end_reason=completion` 提前 finished，后 3 题未作答；结算比分 s10002 300 : s10001 268。
- **复现步骤**：
  1. 两人入队配对后，慢速/跨超时作答；
  2. 观察 `vocab_pk_player.answered_count` 与作答行数；
  3. 查看对局是否在题位未满前进入 finished。
- **证据**：`pk-match-db.txt`、`pk-match-final.json`；DB：match `finished / current_item_index=3 / completion / winner=90e4f9ac…`；两名 player `answered_count=5, correct_count=2`，而 `vocab_pk_answer` 各仅 2 行。代码 `backend/app/services/vocabulary_pk.py`：`_settle_due` 对超时未答空位 `answered_count += 1`（L651），`_settle_if_over` 以 `answered_count >= question_count` 判定完成（L674）。
- **影响面**：慢节奏/弱网学生可能在题位未答完时被结算；`answered_count` 混合「真实作答行」与「超时占位」，计分卡展示的「已答 N 题」与实际作答不符。
- **建议**：产品确认超时跳过口径；若完成判定应基于实际作答行/已处理题位，建议拆分 `answered_count`（真实作答）与 `processed_count`（含超时跳过），结算阈值与计分卡分别取数；并复核慢速走查场景下 3 题未答即 `completion` 是否符合预期。

### D-S4 · P2 · 选择题反馈文案复用拼写口径（中文「拼对了！」）

- **级别**：P2（文案语义缺陷，不影响判分）。
- **现象**：四选一场景答对后，中文反馈仍为「拼对了！」，答错为「差一点点，再看看正确拼写。」；选择题不存在拼写动作，文案应为「选对了/再看看正确选项」类口径。
- **复现步骤**：自主练习或任务练习进入 en_zh/zh_en 选择题，答对/答错查看反馈标题。
- **证据**：截图 03（选择题答对显示「拼对了！」）；代码 `frontend/src/components/Vocabulary/Practice/AnswerFeedback.tsx` L86、L88，反馈文案未按题型（选择/拼写）分流。
- **影响面**：中文界面选择题场景文案语义不准；英文 `Correct!` 不受影响。
- **建议**：按 `prompt_type` 分流反馈文案：选择题「选对了！/ 再看看正确选项」，拼写题保留「拼对了！/ 再看看正确拼写」。

### D-S5 · P2 · 任务练习页头部首答计数不随作答实时刷新

- **级别**：P2（展示滞后；刷新后数据正确，不落库错误）。
- **现象**：任务练习过程中，头部「首答正确 N」在作答后不即时更新（前 4 题答对后头部仍显示 0），刷新页面后才恢复为 4。自主练习页头部可实时更新。
- **复现步骤**：进入已派发任务练习页，连续答对数题，观察头部首答计数；刷新后再看。
