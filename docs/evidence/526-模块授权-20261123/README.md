## 4. 服务端闸门口径（API 探针摘要，详见 `api-probe.json`）

- `/modules/me`：A 校三角色 `["speaking"]`；B 校三角色 `["vocabulary"]`。
- 模块未购：403 `module_not_enabled:speaking` / `module_not_enabled:vocabulary`。
- 角色解析先于模块闸门：未入班 / 非教师访问底座接口返回 404 `Student not found` 或 403 教师授权文案，不冒充模块 403。
- 401 仅用于 token 无效/过期；本次探针未出现 401 混入模块闸门口径。
- 停用租户：403 `Inactive tenant`，与模块 403 文案不同。

## 5. 发现的问题（未自行修改业务代码）

### B1 · 词汇任务页头部「口语练习」链接未按 speaking 模块隐藏（轻微 UI 瑕疵，无数据泄露）
- 现象：B 校（speaking 关、vocabulary 开）教师进入 `/t/VJS6CD/vocab`，页面头部仍展示「口语练习」切换链接，指向 `/t/VJS6CD`。
- 复现步骤：
  1. 以 B 校教师 `teacher-b@e2e526.seed` 登录本地前端；
  2. 打开 `/t/VJS6CD/vocab`；
  3. 观察头部右侧：「口语练习」链接可见（对照截图 `14` 右上角）；
  4. 点击该链接：被口语路由守卫弹回 `/classrooms`，无口语数据泄露。
- 对照实现：口语面板头部的词汇链接已用 `hasModule("vocabulary")` 门控（`frontend/src/routes/t.$code.index.tsx`）；词汇任务页头部的口语链接（`frontend/src/routes/t.$code.vocab.tsx` 头部「口语 / 词汇」切换区）未做对称门控。
