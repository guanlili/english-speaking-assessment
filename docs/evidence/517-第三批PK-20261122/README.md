## 4. 缺陷 / 缺口与本地修复记录

### 4.1 前端挂载即崩（TDZ 引用）— 本地最小修复，未提交

- 原现象：`PkArena` 挂载即崩，控制台 `ReferenceError: Cannot access 'sseAliveRef' before initialization`。
- 定位：`matchQuery` 的 `refetchInterval` 闭包引用了声明在 `useQuery` 之后的 `sseAliveRef` / `lastEventAtRef` / `forceTick`，处于暂时性死区（TDZ）。
- 本地最小修复：把这三个 ref 声明上移到 `matchQuery` 之前；`tsc --noEmit` 干净，`biome check` 文件本身无 lint 错误（仅配置版本 2.6.4 / 期望 2.6.7 的版本警告）。
- **状态：该修复为本地未提交改动**，未跑 `verify.sh` 全量闸门之外的新验证；其余 PK 后端 / 前端文件为本批新增未跟踪文件，非本轮手写。

### 4.2 教师面板 UI 入口 — 已补并复验通过（第三轮）

- 第一批记录的缺口：学生路由 `/vocab/$code` 守卫要求 student 角色，教师直访 PK 页被重定向，教师词汇页无 PK 入口。
- 修复：教师词汇页 `/t/$code/vocab` 新增「PK 对战」Tab，挂载 `components/Teaching/VocabTasks/PkTeacherPanel.tsx`；教师不经学生路由 `/vocab/$code/pk`。
- 复验结论（真实浏览器，§2.9）：教师 UI 登录 → 选库 / 题量 / 限时 → 开厅 → 等待玩家 → 进行中对局比分 → 结算 → 关厅全链路走通；面板数据由大厅快照 1.5s 轮询派生。
- **保留的真实限制**：教师不在对局名单内、订阅对局 SSE 会 403，故教师面板不订阅对局实时 SSE，只看大厅快照；等待名单 / 比分存在最多一轮轮询延迟。
