### 口径（代码核对，`backend/app/services/vocabulary_farm.py` / `models/vocabulary/farm.py`）

- 四阶段阈值：0 种子 / 5 发芽 / 12 生长 / 20 成熟；≥20 成熟可收获。
- 每个有效**首答**（`attempt_no=1`，非测验轮）+1 成长点；当日成长上限 30 点；测验（quiz）与重试不计。
- 成熟收获一次 **+10 XP**（写入既有课堂档案 `student.xp`），成长点扣除 20、**剩余保留**；当日农场 XP 上限 10。
- 收获 XP 与徽章复用既有账本（`student.xp` / `student_badge`），不另立并行积分；**streak 不由农场推进或重置**。
- 地块按登录账号 `user_id` 归属（跨班连续）；农场奖励不计入教师任务统计。

## 3. 幂等与上限核验

| 场景 | 结果 | 证据 |
|---|---|---|
| 已收获状态再次请求收获（幂等） | **422**，`{"detail":"作物还没成熟，暂时不能收获"}`；未二次入账（XP 仍 10，累计收获仍 1） | API 片段（收获后重复 POST `/farm/harvest`）；UI 按钮已回落禁用态 |
| 当日农场 XP 上限拒收（cap 分支） | 代码分支存在：`today_farm_xp ≥ 10` → 422「今日农场 XP 已达上限，明天再来收获」。**本批未端到端触发**：当日成长上限 30，收获后今日成长已计 20，当日仅剩 10 点成长额度，无法同日再次长到 20 成熟来走 cap 分支；该分支仅代码核对，未做 UI / API 实测 | 代码 `services/vocabulary_farm.py` `harvest()` |
| 重复首答 / 重试不计成长 | 本批未做负向专项测验；口径以代码为准：仅非测验轮 `attempt_no=1` 进入 `record_valid_first_answer` | `routes/vocabulary_assignments.py` 266–275 行 |

## 5. 观察到的问题与限制

1. **徽章名称 / 描述双语 — 已修复并复验通过**：第一批取证时英文 locale 徽章条目曾直出中文（后端 `BADGE_BY_KEY` 中文定义被农场视图直接渲染）。修复后前端 `lib/farm.ts` 新增 `badgeText()`：按 key 给既有 5 个 + 农场 2 个徽章双语名与描述，未知 key 回落后端原文；`FarmPlotView` 徽章区改用它。复验（截图 09，820 英文）：徽章显示 **First Harvest / Harvest your first mature crop**，来源 chip **Focus Farm**；`main` 内无中文 UI 残留，无横向溢出，按钮 48px。残留说明：侧边栏头像旁的「学生A」「我的课堂 · AY6S7T」是后端账号展示名（数据，非界面文案），不在本次双语修复范围。
2. **cap-422 分支未实测**：见 §3，受当日成长上限 30 约束，同日无法再次成熟；留待跨日或专门夹具验证。
3. 收获按钮在禁用态仍占整行宽度（设计如此）；各档触控高度 48px，满足 ≥44px 要求。
