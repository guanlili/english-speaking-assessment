## 4. 隐私结论

- 匿名开启时，学生 / 教师榜单条目只下发 `alias_no` 与展示编号，**不下发** `student_id`、`user_id`、`email`、`open_id` 等任何身份标识（字段清单见 T5）。
- 关闭匿名后仅在教师设置允许时下发 `display_name`（及同名消歧 `suffix`）；实名态同样不下发 ID / 邮箱。
- 未参加学生看不到任何人与人数；参与人数仅教师视角可见。
- 本目录截图与机读证据未出现真实邮箱、`open_id`、token 或生产地址；演示账号为本地合成占位标识。
