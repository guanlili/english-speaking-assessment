# 学生词汇坐标口径（coord-v1，2026-11-28）

对应需求：issue #616（父单 #615）。手册 v4 §03 的「0%–100% 贯通词库」按本条口径落地，
**以我方设计为准，手册只作参考**。

## 一句话

坐标 = 你已经掌握的词 ÷ 你当前能练的词，换算成 0%–100%，再按等宽台阶切段。
它是学习进度，不是雅思/托福分数，不是能力认证，也不预测考试分数。

## 分子：什么算「掌握」

只认两类证据，其余一概不读（XP、农场、PK、任务完成率、首答正确率都不参与）：

1. **独立首答答对**：`VocabularyAnswer.attempt_no = 1 and is_correct = true`。
   任务轮、自主练习轮、复习轮都算；测验轮沿用错词本同一条答案可见规则
   （公布前不计入，避免「提前知道对错」污染证据）。
2. **FSRS 进入长期记忆**：`vocabulary_review_state.state = "review"`
   （认读 / 拼写任一能力维度），按登录账号跨班汇总。

两源合并去重：同一个词既首答对过、也进过 review，只算 1 个词。

## 分母：基准词表

`student_practiceable_word_ids(classroom)`：本班当前可练的词条集合——

- 词库 `status = active` 且属于「公共库」或「本班库」；
- 词条 `status = active` 且 `review_status = approved`。

分子、分母都按**当前**口径取交集：词条归档后不再计入分子，分母同步缩小，
所以百分比可以整体复算——两个数都会随接口一起下发。

## 换算

```
percent = round(100 × mastered / basis)        # 上限 100，四舍五入到整数
step_width = 100 / steps
step_index = min(steps, floor(percent / step_width) + 1)   # 1 起，左闭右开
step_start = int((step_index - 1) × step_width)
step_end   = 100 (最后一阶) / int(step_index × step_width)
words_to_next_step = max(0, ceil(basis × step_end / 100) − mastered)   # 最后一阶为 0
words_to_goal      = max(0, basis − mastered)
```

台阶数量 `steps` 默认 12，接口可传（夹在 2–40）；**不把 12–18 写死**，
教研口径定了再配置，不靠台阶宣称等级。

## 未测与边界

| 情况 | 返回 | 前端 |
| --- | --- | --- |
| 基准词表为 0（还没建可练词库） | `measured=false`，percent/台阶全 null | 显示未测 |
| 一条独立首答都没有 | `measured=false`，percent null，`words_to_goal=basis` | 显示未测，**不折算 0%** |
| 掌握数 ≥ 基准词数 | `percent=100`，最后一阶，两个「还差」都是 0 | 100% |
| 词条归档后 | 分子分母同步缩，历史作答不迁移不改写 | 百分比复算 |

## 已知边界（不做但不隐瞒）

- **跨班连续**：作答历史挂在学生档案（按班建），换班后历史不合并；
  FSRS 状态按账号跨班，是唯一跨班连续的信号。要真正跨班累计，需要另立
  「账号级掌握表」，属于后续迭代（#616 待办）。
- **教师端按台阶分布 / 按台阶派发**：本批先做学生端；教师侧另起一批，
  仍需按本口径复算，不重算一套。
- 词表规模：当前基准是平台可练词表，不是手册里的 10,000 词；换基准只改分母，
  台阶与文案不用动。

## 复算示例

基准词表 100 词、掌握 43 词 → `percent = round(43) = 43`；
12 阶口径 `step_width = 8.333`，`43 / 8.333 = 5.16 → step_index = 6`，
本阶区间 41%–50%，距本阶终点 `ceil(50) − 43 = 7` 词，距 100% 57 词。
