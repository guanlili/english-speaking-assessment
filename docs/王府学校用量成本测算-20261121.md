整理日期：2026-11-21。用途：按校方老师预估使用量，测算**理论最大成本**与保本报价下限，避免包干报价亏本。成本模型与单价沿用 `pricing-assessment-2026-10.md`（2026-10-22 生产实测校准）。

**保本报价建议（国内合规口径，全成本）**：

- **包干下限：¥3,400/月（¥40,800/年）**——覆盖理论最大全成本并留约 18% 余量；
- 稳妥报价：**¥3,600/月（¥43,200/年）**，留 25% 余量应对流量/重试/资源包外价格波动与升级；
- 按生定价：**≥¥100/生/年**（518 人 ≈¥51,800/年），在国内任意模型档位下均不亏本；¥120–150/生/年含实施培训毛利。

> 平台部署在国内、学生语音数据不出境，全球模型档受个人信息保护与生成式 AI 合规约束，**不是可选项**；其数字仅作数学上限压力测试，不进入报价依据。

## 3. 理论最大成本测算

### 3.1 强度档位定义

| 档位 | 练习强度假设 | 开口占比 |
| --- | --- | --- |
| A 校方预估 · lite | 初中 2h/周；高中 134 人每天 1h、其余 1h/周 | 50% |
| B 校方预估 · 旗舰拉满 | 同上强度，句句录音 | 100% |
| C 全员每天练 · 旗舰（国内最大） | 518 人全员每天 1h（7h/周） | 100% |
| D 全球旗舰档（压力测试，不可选） | 同 C | 100% |
| E 全球最贵档（数学上限，不可选） | 同 C | 100% |

### 3.2 音频小时与作答量（档位 C 示例）

- 全员每天 1h：518 × 7h/周 × 4 周 = **14,504 练习小时/月**；
- 开口 100% → 音频 **241.7 小时/月**；
- 作答次数：241.7h ÷ 19.7s ≈ **4,428 次/月**；问答题 ≈1,727 次。

## 5. 容量与前置配置

518 人落在现有双 g4i（4C16G×2）承载范围内，**无需加机器**（对照 §1.7：500 人档）。开考前落实：

1. `SCORING_WORKERS` 8→16（全校同刻模考评分吞吐）；
2. EIP 峰值上限 100M→200M；
3. `AUDIO_TTL_DAYS=180` 必开（重度音频月增 ≈20G+，不开一年顶满 500G 盘）；
4. 火山控制台确认/提额 ASR 上游并发配额；
5. 教师/管理员 50 账号不产生 ASR 费用。

## 6. 风险与口径说明

1. **开口占比是最大变量**：练习以跟读/听为主则 ASR 大降；句句录音则上升。上线首月须用真实音频小时数回填本模型，修正报价。
2. 单价为公开按量价，未计资源包/新客折扣，实际现金支出只会更低；TTS 标准音为教师一次性，≈¥20 封顶。
3. 全球模型档受合规约束不可选，仅作数学上限；代码侧 `max_tokens 2048` 硬护栏已封死 LLM 输出失控。
4. 平台模考为练习参考分，不替代 Aptis/TOEFL/IELTS 官方测评；外部测评费用另算。
5. 本测算不构成最终报价承诺；合同金额、结算方式以双方签署为准（见 `project-profile.md`）。
