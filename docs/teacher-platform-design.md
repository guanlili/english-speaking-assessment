# Charcoal 教师平台设计

## 产品定位

服务一堂口语课的完整流程：老师准备内容、组织学生练习、查看录音和反馈、安排下一次教学。教师端不展示激励运营、词表维护、账号权限等无关入口。

老师只需理解三个对象：课堂、练习、题目。课堂用于组织学生；一份练习容纳有序的题目；题目只有文章朗读、听句复述、模拟问答三种。

## 导航与页面职责

- 我的课堂（登录默认页）：创建课堂、进入教学空间；导入学生与名单放在次级操作。
- 题目库：按三种题型出题、预览、搜索和复用。
- 平台设置：仅管理员可见、默认折叠，容纳账号权限、词表及兼容旧数据的维护功能。

不再增加一个重复罗列功能的“教学工作台”。学习单元、情景、问法是内容组织细节，不作为教师的一级菜单。

课堂教学空间的目标结构：

1. 课堂练习：练习列表、当前发布、创建下一次练习、历史归档。
2. 学生结果：按练习查完成情况、录音、转写与参考反馈。
3. 学生管理：导入、加入、移出、账号恢复。

当前版本将练习安排与结果放在课堂内，学生名单保留在课堂卡片的次级区域。

## 三种出题体验

| 题型 | 老师准备 | 老师配置 | 学生过程 |
| --- | --- | --- | --- |
| 文章朗读 | 英文文章或段落；可选中文提示与参考音 | 作答时长、难度 | 阅读题目 → 录音 → 提交 → 参考反馈 |
| 听句复述 | 一句英语与标准音 | 作答时长、可听次数，0 表示不限 | 听音 → 按剩余次数重听 → 复述录音 |
| 模拟问答 | 英文问题、可选提示和音频 | 难度、答题时长、顺序 | 听题 → 自由作答 → 下一问 |

AI 出题是问答编辑器内的辅助能力，生成结果为待审核草稿，明确采纳才写入；保存失败保留草稿。AI 功能不可用时仍可手动出题。

目标版本中，三种题型均可独立创建，复述和纯问答不要求老师先建一篇文章。所有已发布题目采用快照，修改题库只影响未来发布。

## 课堂备课与发布

目标流程：进入课堂 → 新建练习 → 添加或复用题目 → 调整顺序与参数 → 预览 → 发布给本课堂 → 查看结果 → 归档。

编辑与发布必须分开。选择内容、勾选题型不立即改变全班练习。发布前校验空题单、题干、播放次数、时长和音频准备情况；问答只需该主题有题即可（2026-09-29 起不分级，全班同题，老师自由编排）。

发布摘要必须展示目标课堂、内容、题型和题量。发布失败保留选择，成功后明确显示当前发布内容。不把“清除指派”称为“结束考试”：清除目前意味着恢复自主练习。

## 成熟版需要的数据结构（设计，部分已落地）

- Classroom：课堂名称、年级/班型、教学目标、教师归属、成员、启用状态。课堂码只是加入方式，不替代课堂名称。
- Question：类型与题干，附难度、时长、参考音、复述播放次数；不通过主题字符串隐式关联。
- Exercise：所属课堂、标题、草稿/发布/结束/归档状态；题目有序关联。
- ExerciseVersion：发布时保存题目与参数快照；已开始的学生会话固定关联版本。
- Submission：关联学生、练习版本与具体题目；录音、评分、反馈独立存储。

创建练习、保存有序题单、发布版本应分别提供事务 API，避免多次前端请求导致半保存。权限验证以课堂教师归属为准；题目库应区分个人和校内共享，复用他人内容默认复制，不能随意修改他人已发布练习。

结果页需分开显示提交人数、完成全部题目人数、评分中人数、待关注人数；分数标注参考并注明来源。历史结果始终按当时题单解释，不能随题库编辑变化。

## 本次已实现

- 一级导航收敛为我的课堂与题目库，首页直接进入课堂，平台设置默认折叠。
- 题目库按三种题型展示，听句复述支持编辑句子、时长、可听次数；问答保留手动、AI 草稿和批量入口。
- 课堂统一保留导航，练习安排与结果分开。
- 指派改为选择内容、选择题型、完整性检查、内容预览、确认发布。
- 未选题型、无材料、缺复述句、主题无问答题时阻止新界面发布；多档问答齐备要求已随"问答不分级"决策移除。
- 补题入口带课堂上下文，可直接返回原课堂继续安排。
- 当前操作使用真实生成客户端和原有数据，无模拟发布或假统计。
- 课堂支持自定义名称、年级/班型和教学目标，课堂码只作为学生进入课堂的凭证。
- 结果页增加教学动作：复制未完成学生的提醒文案、复制单个学生的反馈提示、直接进入下一次练习安排。
- 课堂难度由教师选题和发布内容决定；A2/B1/B2 仅保留为词表和评分的内部元数据，不再出现在学生或教师课堂流程中。
- 课堂实测后修复：复述题听数跨句泄漏导致误锁死（按题号重挂载）、教师面板录音收起再展开后失效（objectURL 缓存与撤销生命周期错配）、结果页朗读题型缺失中文标签、学生首页题量文案改为按实际指派计算、周历打卡本地日期修正、评分引擎标签识别豆包语音引擎。
- 历史拆段朗读版本曾将文章拆成多篇；#88 曾统一为整篇一道题（分句仅折叠展示）。2026-10-08 起拆句真正下发：拆分文章按句出题、学生逐句朗读（见下条），已发布的历史题单仍按原快照解释。
- 三题型独立（2026-09-29）：复述句独立题库（不挂篇目可直接创建/指派）；发布器改为按题选题，题目集合存于课堂（assigned_items），学生计划/教师面板/换题按题组装。
- 朗读文章树（2026-10-08）：朗读分句按原文顺序折叠在文章下，组卷直接勾选整篇文章；编辑正文后分句展示自动更新。拆分过的文章在发布/练习时按句展开成逐句朗读题（每句单独录音评分，作答限时按句长推算 4–30 秒），句子条目用 uuid5(passage_id, 句序) 的确定性合成 ID，只在快照/题单层存在、不建篇目行；`DELETE /admin/passages/{id}/split` 可取消拆分回到整篇一道题。旧版按段/按句拆出的独立篇目仅在归属完整且唯一时迁回原文章，保留 ID 和已发布快照。听句复述的自动拆分是另一项操作，从正文选 3 句生成听音后复述题。
- 课堂删除（2026-10-08）：确认永久删除后可清理测试课堂的完整历史，包括已移出成员的口语与词汇记录；学生账号及其他课堂保留。停用课堂同样可删除，评分中记录需等待评分结束。
- 模考逐题规则（2026-10-08）：服务器按发布快照顺序计时，准备结束后进入作答时间。到时自动停止并提交录音、进入下一题，未录音的题保留为未作答；提交后无需等待评分。刷新不能重置时间或回到旧题；结果页仅可回放，移除重练与换题入口。

## 本次仍保留的底层边界

当前实现已补上发布版本快照：课堂发布会生成不可变的练习版本，题目文本、音频地址、建议时长和复述次数随版本保存；学生当日会话、作答提交、评分 worker 与教师面板均优先使用该版本。题库后续修改只影响下一次发布，旧版本仍可通过课堂练习历史接口回看。旧课堂若尚未重新发布，仍按兼容路径读取原有指派。

课堂按三种题型独立选题。朗读直接选择整篇文章，展开文章可查看原文顺序的分句，分句没有单独的组卷复选框；拆分过的文章发布后按句展开（学生逐句朗读、每句一题，指派镜像仍存整篇 ID）。听句复述选择独立句库，情景问答选择题目；历史拆分题重选时归回原文章。旧发布仍读原快照，题库调整只影响后续发布。

发布校验当前属于交互防护，尚不是后端一致性保证。多教师同时修改、绕过页面调用接口等情况，需要在正式发布 API 中重新校验并事务保存。

## 验收路径

1. 登录后只看见我的课堂和题目库；管理员设置折叠。
2. 从课堂进入题目库，三种题型各有清晰说明，可返回同一课堂。
3. 设置复述可听次数后再打开，值保持一致；仅更新音频不重置播放限制。
4. 勾选、选择内容不会发布；至少一种题型且内容齐备才能预览。
5. 发布成功刷新当前课堂；失败保留输入。
6. 学生结果独立于备课表单，录音和参考反馈可回看。
7. 朗读文章可折叠查看分句，选择一次即选整篇；未拆分文章计为一道题，拆分文章按句展开（预览与题单标注逐句题数）。
8. 冗余/停用课堂在确认后可删除，清空成员后仍能清理归档历史；评分未结束时保留确认框并提示稍后重试。
9. 模考每题倒计时到时自动推进，刷新不会回到上一题；最后一题完成/到时进入结果页，结果页可回放但不提供重答入口。普通练习仍可重练。
