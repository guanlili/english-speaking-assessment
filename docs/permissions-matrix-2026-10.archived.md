# 平台角色与权限说明（2026-10）

> 面向校方的权限说明。平台共三类登录角色，所有权限均由系统强制执行：
> 看不到的功能不会出现在菜单中，直接输入网址访问也会被拦截。

## 一、角色总览

| 角色 | 如何登录 | 定位 |
|---|---|---|
| **管理员** | 邮箱账号（平台交付时设置） | 平台负责人：全局数据、账号、内容与费用总览 |
| **教师** | 邮箱账号（管理员创建） | 只管自己的课堂：出题、发布、看本班数据 |
| **学生** | 学号 + 密码（教师批量导入建号） | 只看自己的练习记录与成长数据 |

未登录访客无法访问任何页面；**课堂码只能用于学生加入课堂，凭课堂码查看不到任何班级数据**。

## 三、关键数据边界（一句话版）

1. **教师之间互不可见**：每位教师只能看到自己负责的课堂与学生的数据。
2. **学生只看自己**：任何情况下看不到同学的数据，也看不到教师的课堂管理页。
3. **大盘只属于管理员**：全平台使用情况、性能与费用信息，教师与学生既看不到入口，直接访问网址也会被系统拦截。
4. **权限由系统强制**：以上边界是平台内置的访问控制，不依赖使用者的自觉。
