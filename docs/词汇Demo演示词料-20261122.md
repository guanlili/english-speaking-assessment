# 词汇 Demo 演示词料（2026-11-22）

对应需求：GitHub Issue #517「词汇教学 Demo（第一批：四类玩法 → 闭环）」。

## 文件

- `backend/scripts/demo/vocab-demo-words.csv`：18 条自编演示词条。
- 表头与现有导入一致：`headword,meaning_zh,part_of_speech,meaning_en,accepted_spellings,example_en,morphology`。
- `morphology` 为 JSON 数组字符串（`[{"text","gloss","kind"}]`，kind 取 prefix/root/suffix）。

## 覆盖什么

| 出题方式 | 可出题词条 | 说明 |
| --- | --- | --- |
| 英译中 / 中译英（四选一） | 18 | 每词都有中文释义，足够生成 3 个干扰项 |
| 语境填空 | 18 | 每词都有包含该词原形的例句 |
| 词根拼装 | 14 | teacher / preheat / unhappy / rethink / helpful / kindness / bookmark / notebook / sunlight / rainbow / popcorn / teapot / sunflower / writer / disable 等 |

## 怎么用

1. 教师端 → 词汇学习 → 词库 → 新建班级词库 → 导入 CSV（先预览，确认无 invalid 行）。
2. 发布任务时勾选四类玩法中的一种或多种；四选一至少选 4 个词。
3. 素材不足时发布会 422 并说明缺什么（例句 / 词法 / 干扰项），不会出空题。

## 审核状态（重要）

- 词条释义、例句、词法拆解均为 **AI 起草的演示语料**，按「待审核」处理。
- 教学准确性由学校老师负责；本文件不代表任何老师已验收。
- 语料为自编常见词，不引用版权词表；正式上线前需替换为学校教材词表或经老师审核的词表。
