# 每日挑战口径（2026-11-28，#618）

每日挑战是学生端「加练入口」，不是老师任务的一部分。

## 一、出题规则

- 维度固定四种：**拼写 / 认读 / 语境 / 词法**，每个挑战包最多从三个维度各取 1 款，共 3 款。
- 每款 5 词，整包 15 题；素材不足的维度直接跳过，并在学生端写明原因（比如「语境维度素材不够」），不凑空题。
- 维度顺序、玩法选择、取词顺序都由 `seed(班级ID + 日期)` 决定：**同班同一天所有人看到同一套配置**，刷新、换设备、换老师看都是同一份；词库改了内容，题面跟着词库走，但选词规则不变。
- 现阶段只从「本人可练词表」取词（公共库 + 本班已发布词库），所以不同班、不同词库的学生拿到的词不同，配置结构相同。

## 二、口径隔离

- 挑战轮 `kind="daily_challenge"`，没有 `assignment_id`：
  - 不进教师任务完成率、不进任务首答成绩；
  - 不参与课堂 PK、榜单的任务口径（后续做榜单时按玩法口径单列）；
  - 作答照常留痕，错词本与词汇坐标仍按「独立首答」累计。
- 完成状态：当天（本地日界 UTC+8）有已提交的挑战轮即为已完成；当天再点「再练一轮」会新开一轮，完成状态保持。
- 未完成的轮当日可续做（刷新/换端回到同一题单）；跨天不会自动续，视为前一天弃练。

## 三、边界

- 不做排名、不发奖励、不影响 XP；农场/榜单要接的话另立口径。
- 素材判定沿用既有题型规则（拼写看词条本身、听音看 `audio_url`、语境看例句能否挖空、词法看词根是否可拼），不额外造数据。
- 题库只有释义、没有例句和词根时，实际只出 2 款（拼写 + 认读），属预期降级，不算故障。
